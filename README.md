## file_sorter

Скрипт раскладывает файлы из указанной папки (по умолчанию - системная «Загрузки» на Windows) по подкаталогам в зависимости от расширения, а для `.exe` - ещё и от имени файла
(`setup` -> `installer`, остальные -> `program`).

### Возможности

- Автоопределение стандартной папки «Загрузки» на Windows (через реестр).
- Сортировка произвольной папки через аргумент `--path`.
- Целевые подкаталоги создаются автоматически, если их нет.
- Файлы **не перезаписываются**: при совпадении имён файл пропускается с сообщением.
- Разные коды возврата для разных сценариев (см. ниже).

### Категории

| Категория | Расширения |
|---|---|
| `image` | `.jpg`, `.jpeg`, `.png`, `.gif` |
| `document` | `.pdf`, `.docx`, `.txt` |
| `archive` | `.zip`, `.rar` |
| `video` | `.mp4`, `.avi` |
| `music` | `.mp3`, `.wav` |
| `installer` | `.exe`, если в имени встречается `setup` |
| `program` | прочие `.exe` |

Файлы с другими расширениями остаются на месте.

### Требования

- Python 3.10+ (используются `str | None`, `list[...]`, `collections.abc.Callable`).
- Автоопределение папки «Загрузки» работает только на Windows. На других ОС обязательно указывайте `--path`.

### Запуск

```bash
# Windows: сортировать системную папку «Загрузки»
python file_sorter.py

# Любая ОС: сортировать конкретную папку
python file_sorter.py --path "/home/user/Downloads"
```

### Коды возврата

| Код | Значение |
|---|---|
| `0` | Все файлы успешно отсортированы |
| `1` | Фатальная ошибка: неверный путь, не удалось создать папки, не удалось получить путь по умолчанию, либо часть файлов не удалось переместить |
| `3` | Некоторые файлы пропущены - в целевой папке уже есть файл с таким именем |
